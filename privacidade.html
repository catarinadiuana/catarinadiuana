Que dados são recolhidos

Este site não tem formulários nem recolhe dados automaticamente. Os únicos dados recolhidos são os que fornece voluntariamente ao entrar em contacto:

— Por WhatsApp: nome e mensagem
— Por email: nome, endereço de email e mensagem
— Por Google Calendar: nome e email para efeitos de marcação

Para que são usados os dados

Exclusivamente para responder ao seu pedido de contacto ou para gerir a marcação de consulta. Os dados não são usados para fins comerciais, não são partilhados com terceiros e não são utilizados para envio de comunicações não solicitadas.

Durante quanto tempo são guardados

Os dados são mantidos apenas enquanto necessário para a prestação do serviço, respeitando as obrigações legais aplicáveis à prática clínica em Portugal.

Os seus direitos

Ao abrigo do Regulamento Geral de Proteção de Dados (RGPD), tem direito a aceder, corrigir ou solicitar a eliminação dos seus dados pessoais. Para o fazer, envie um email para catarinadiuana@gmail.com.

Cookies

Este site não utiliza cookies de rastreio nem ferramentas de análise de comportamento.
